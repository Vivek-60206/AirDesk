# AirDesk - Gesture Guide

The following mappings describe the currently configured interaction model.

| Hand gesture | Desktop action | Notes |
|---|---|---|
| Index Finger | Move cursor | Hand position controls pointer position |
| Pinch | Left click | Pinch detection triggers a click |
| Victory (two fingers) | Scroll | Gesture controls scrolling direction |
| Thumb Up | Volume up | Increases system volume |
| Thumb Down | Volume down | Decreases system volume |
| Closed Fist | Mute / unmute | Toggles audio mute state |

## Safety controls

- **F8:** Pause or resume gesture control.
- **Emergency Stop:** Immediately stop gesture-driven control.

## Usage tips

- Keep the hand visible within the camera frame.
- Use steady, even lighting.
- Avoid placing the camera too close to the hand.
- Test the controls in a safe, non-critical application before relying on them.

Gesture recognition may vary with camera quality, lighting, hand position, and background conditions.
