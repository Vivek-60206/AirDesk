APPLICATION DESIGN

A native Windows experience.

AirDesk uses a PySide6 desktop interface alongside its computer-vision and desktop-interaction components. The public website is a separate product showcase, not the application itself.

INTERACTION SAFETY

Control remains accessible.

The application includes pause/resume and Emergency Stop controls. These provide ways to interrupt gesture-driven interaction when needed.
